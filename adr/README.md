# Architecture Decision Records (ADR)

Зафиксированные архитектурные решения. Каждый ADR — короткий документ:
**контекст → решение → последствия → статус**.

## Формат

- Имя файла: `NNNN-краткое-название.md` (порядковый номер).
- Статусы: `Proposed` (предложено) · `Accepted` (принято) · `Superseded` (заменено).
