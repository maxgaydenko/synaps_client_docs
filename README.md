# Synaps Client — документация

Проектная документация по созданию **production-клиента на Qt 6 + QML** (db-manager)
на смену Flutter POC (`ddbs_client`). Документы организованы по фазам:
**концепция → архитектура → план работ → выполнение**.

## Навигация

| Раздел | Содержимое |
|---|---|
| [00-overview/](00-overview/) | Обзорные документы. **Точка входа** — концепция и требования. |
| [01-concepts/](01-concepts/) | Углублённое описание ключевых концепций (Query/QueryManager, подписка, TabManager, слои/MVVM). |
| [02-architecture/](02-architecture/) | Артефакты фазы архитектуры (детальный дизайн, диаграммы). |
| [03-protocol/](03-protocol/) | Детальная спецификация протокола QL и его flow. |
| [adr/](adr/) | Architecture Decision Records — зафиксированные решения. |

## С чего начать

➡️ **[00-overview/architecture-concept.md](00-overview/architecture-concept.md)** —
главный документ-концепция: видение, протокол QL, ключевые концепции
(Query / QueryManager / подписка / TabManager / разделение слоёв), требования и
рекомендуемое направление архитектуры. Это вход для фазы проектирования архитектуры.

Сопутствующее: [глоссарий](00-overview/glossary.md).
